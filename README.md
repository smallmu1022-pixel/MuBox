# MuBox for Android

An Android proxy client powered by the sing-box core.

> **Fork notice**: This project is a fork of [KunBox v2.24.3](https://github.com/roseforljh/KunBox) by **roseforljh** — many thanks to the original author. It has been rebranded and re-signed, and is maintained independently; it is not affiliated with the original project.

## Download

Get the latest APK (arm64-v8a / armeabi-v7a) from [Releases](https://github.com/smallmu1022-pixel/MuBox/releases).

## Notes

- Full edition: keeps all protocols and features of the original project (VLESS, VMess, Trojan, Shadowsocks, Hysteria, Hysteria2, TUIC, WireGuard, AnyTLS, and more)
- For a slim edition, see [MuBox-Slim](https://github.com/smallmu1022-pixel/MuBox-Slim): only 6 common protocols with a self-built trimmed core, about one third smaller
