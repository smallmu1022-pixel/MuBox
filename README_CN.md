# MuBox for Android

基于 sing-box 内核的 Android 代理客户端。

> **Fork 说明**：本项目 Fork 自 [KunBox v2.24.3](https://github.com/roseforljh/KunBox)（原作者 **roseforljh**），在此向原作者表示感谢。本项目在原作基础上更换品牌与签名、独立维护，与原项目无关。

## 下载

在 [Releases](https://github.com/smallmu1022-pixel/MuBox/releases) 下载最新版 APK（arm64-v8a / armeabi-v7a）。

## 说明

- 完整版：保留原项目全部协议与功能（VLESS、VMess、Trojan、Shadowsocks、Hysteria、Hysteria2、TUIC、WireGuard、AnyTLS 等）
- 精简版另见 [MuBox-Slim](https://github.com/smallmu1022-pixel/MuBox-Slim)：只保留 6 种常用协议、自编裁剪内核，体积小约三分之一
